# 🎨 ParuKuat — UI Guidelines

# UI Philosophy

ParuKuat menggunakan pendekatan:
- calming healthcare UI
- soft therapeutic interaction
- lightweight gamification

UI harus terasa:
- nyaman
- lembut
- tidak intimidating
- mudah dipahami

---

# Design Principles

## 1. Simplicity First
Hindari:
- terlalu banyak statistik
- dashboard penuh data
- visual terlalu kompleks

## 2. Soft Interaction
Semua interaction:
- smooth
- tidak agresif
- tidak terlalu cepat

## 3. Large Comfortable Spacing
Gunakan spacing yang lega.

Avoid:
- layout terlalu padat
- text terlalu rapat

---

# Card Design

## Style
- rounded corner besar
- soft shadow
- gradient ringan
- clean surface

## Avoid
- border keras
- shadow terlalu tebal
- dark heavy UI

---

# Typography

## Font
Manrope

## Typography Direction
- clean
- modern
- soft readability

## Avoid
- font decorative
- font terlalu tipis

---

# Animation Guidelines

## Preferred Animation
- fade
- smooth scale
- breathing motion
- slow transition

## Preferred Widgets
- AnimatedContainer
- AnimatedOpacity
- TweenAnimationBuilder

## Avoid
- excessive bounce
- flashing effect
- shaking animation
- fast transition

---

# Dashboard Guidelines

## Dashboard Role
Dashboard bukan medical analytics panel.

Dashboard harus:
- ringan
- motivating
- visually relaxing

## Dashboard Components
- greeting section
- daily recommendation
- progress summary
- breathing trend
- streak reminder

---

# Guided Breathing Guidelines

## Experience
Guided breathing harus terasa:
- meditative
- rhythmic
- therapeutic

## Visual
- expanding breathing circle
- inhale / hold / exhale instruction
- smooth transition

---

# Balloon Game Guidelines

## Game Philosophy
Mini game hanya sebagai:
- therapy support
- engagement booster

Bukan competitive game.

## Visual Style
- minimal HUD
- clean layout
- soft animation
- floating interaction

---

# Performance Guidelines

## Required
- smooth 60fps
- lightweight rebuild
- optimize animation

## Avoid
- unnecessary repaint
- heavy widget tree
- excessive particle effects

---

# Accessibility

## Required
- readable font size
- simple navigation
- high readability
- comfortable interaction area

---

# Responsive Guidelines

UI harus:
- responsive Android
- tetap nyaman pada layar kecil
- tidak overflow
